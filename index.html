⚡ 一鍵超人｜後台 API 版

今天哪些台股值得先觀察？

這版會透過自己的後台 API 讀取 TWSE / TPEx 公開資料，避免手機瀏覽器 CORS 擋住，產生進場區、停損區與觀察清單。

🎯 操作區

產生觀察清單

部署到 Vercel 後，按一次就會呼叫 /api/market/latest。

還沒載入資料。按「測試後台」或「產生清單」。
如果你現在還在 GitHub Pages 網址，後台 API 不會存在；請部署到 Vercel 後使用 Vercel 網址。
💡 看懂清單

只看三件事

🧲 進場區價格來到可以開始觀察的位置，不是一碰就買。
🕯️ 止跌訊號紅 K 或長下影，代表下跌暫時有被接住。
🛑 停損區跌到這裡代表看錯，已進場就要先退場。
一句話：進場區是等機會；停損區是看錯離開。
