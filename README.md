# 一鍵超人

手機外部瀏覽器可開啟的台股觀察清單網頁。

## 公開網址

GitHub Pages 部署完成後，網址會是：

https://qop2722-dot.github.io/oneclick-superman/

## 使用方式

1. 用手機 Safari / Chrome 開啟上方網址。
2. 按「🚀 產生清單」。
3. 查看每檔股票的進場區、停損區與三個燈號。

## 注意

這是觀察清單工具，不是自動下單，也不是保證獲利。進場區是等待位置，停損區是看錯離開的位置。

公開版不放 API Key，主要讀取 TWSE / TPEx 公開日線資料。若需要 FinMind / Fugle、即時報價與更完整歷史資料，請改用後台 API 版。
